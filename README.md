# Website-Creator

本仓库用于《商务网站开发与管理》课程作业提交，当前主项目为 CinemaFlow。

## 上机课提交概览

- 第一次上机课：Angular 基础组件开发
- 第二次上机课：Service 层架构与豆瓣风格功能扩展
  说明文件：[`第二次上机课作业说明.md`](./第二次上机课作业说明.md)
- 第三次上机课：CinemaFlow 路由配置、页面导航与界面展示
  说明文件：[`cinema-flow/README3.md`](./cinema-flow/README3.md)

## 第三次上机课重点

- 项目名称：CinemaFlow 电影管理系统
- 技术栈：Angular 19、TypeScript、Angular Router、Angular Material
- 主要页面：`/home`、`/dashboard`、`/movies`、`/movies/:id`、`/add`、`/about`
- 页面截图目录：[`cinema-flow/screenshots/`](./cinema-flow/screenshots/)

## 运行项目

```bash
cd cinema-flow
npm install
npm start
```

开发服务器默认地址为 `http://localhost:4200/`。
