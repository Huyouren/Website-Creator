About Project

关于 CinemaFlow

CinemaFlow 是一个以 Angular Standalone + Router 为核心的 SPA 项目，目标是用现代化交互管理你的观影记录。

Router 架构 参数化路由 查询参数同步 Material UI
movie CinemaFlow 电影管理系统 v3.0 - Router Edition

这个项目强调“结构清晰、状态可追踪、页面切换流畅”。所有核心能力都围绕路由系统展开，并通过统一视觉语言呈现。

页面组织 模块化
路由方式 懒加载
交互体验 SPA
